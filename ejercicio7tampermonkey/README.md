## Qué hace

- Elimina el banner de donaciones que aparece arriba en el artículo.
- Añade un botón rojo "Subir" fijo abajo a la derecha para volver al principio de la página, porque el artículo es muy largo.

## Cómo probarlo

1. Instalar la extensión Tampermonkey en el navegador.
2. Abrir `dbd-wikipedia.user.js` con el Bloc de notas o VS Code y copiar todo el contenido (no abrirlo con doble click, porque Windows intenta ejecutarlo).
3. Pinchar en el icono de Tampermonkey y elegir Crear un nuevo scrip
4. Borrar el código que viene por defecto, pegar el mío y guardar (File > Save o Ctrl+S).
5. Abrir https://es.wikipedia.org/wiki/Dead_by_Daylight y recargar la página.
