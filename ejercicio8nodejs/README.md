# Ejercicios de node.js (1 al 4)

Abrir una terminal dentro de cada carpeta y ejecutar:

1. `ejercicio1`: `node index.js` (la info sale por la consola; cambiar `config.json` para configurarla)
2. `ejercicio2`: `node leer.js` (el JSON está en `peliculas.json`)
3. `ejercicio3`: `node index.js` y abrir http://localhost:3000/?palabras=5
4. `ejercicio4`: `npm install` y luego `npm start`, abrir http://localhost:3000

Para parar un servidor: Ctrl+C.
